# 实验一 本地测试平台

双击 start.cmd，打开 http://127.0.0.1:8765。首次使用仓库数据，先按根目录 README 执行数据准备。

每块在同一文件内按原顺序累积完整记录，载荷合计达到至少 376 字节时切块，每块调用一次压缩器。训练和测试区独立分块，不足阈值的尾块记录后排除。模式 A 将首部与校验分别保留在载荷前后，统计整块长度；模式 B 仅统计载荷块。ROAD 使用 candump CAN ID 重建的 4 字节逻辑首部，MAVLink 和 DataFlash 使用日志记录中的首部。外层 tlog 时间戳不参与压缩。

测试保留字典训练与测试的数据区间隔离。共享字典默认收发两端预置，只计压缩帧中实际存在的字典 ID。传输采用一个模式字节，压缩不缩短载荷时回退。实验假设外层已提供合并块长度和首部、校验段长度。抽查用的原始记录位置仅用于追溯，不传输边界表。模式 A 验证保留字节和载荷在合并块中的恢复。目标是每个发送块不超过该样本原长度的 80%。

选择数据源、算法、样本数和种子后启动单次实验；「一键跑全部实验」依次测试两个模式，每个模式覆盖 3 个数据源和 4 种算法。「样本抽查」可查看编码输出、实际发送块、恢复数据和逐 bit 验证。「实验结果」支持导出 CSV、JSON、JSONL 和选择多次运行汇总 PDF。「实验记录」可查看配置及日志，暂停或中断后可恢复任务。正式运行数据库位于 runs/experiments.sqlite3。

独立功能验收使用 python smoke_test.py。
在「实验记录」中选中一条记录，点击「删除此实验记录」并确认，可永久清除该实验的结果、样本、字典及日志。运行或排队中的实验不能删除。
