# 实验一 本地测试平台

双击 start.cmd，打开 http://127.0.0.1:8765。首次使用仓库数据，先按根目录 README 执行数据准备。

每次测试以原始文件中的一条有效记录为单位，按实际长度统计。模式 A 保留原有首部和校验，压缩载荷；模式 B 仅测试这条记录的载荷。ROAD 使用 candump CAN ID 重建的 4 字节逻辑首部，MAVLink 和 DataFlash 使用日志记录中的首部。外层 tlog 时间戳不参与压缩。

测试保留字典训练与测试的数据区间隔离。共享字典默认收发两端预置，只计压缩帧中实际存在的字典 ID。传输采用一个模式字节，压缩不缩短载荷时回退。实验假设外层已提供传输块边界，以及所用协议的首部与校验长度，无额外边界表。目标是每个发送块不超过该样本原长度的 80%。

选择数据源、算法、样本数和种子后启动单次实验；「一键跑全部实验」依次测试两个模式，每个模式覆盖 3 个数据源和 4 种算法。「样本抽查」可查看编码输出、实际发送块、恢复数据和逐 bit 验证。「实验结果」支持导出 CSV、JSON、JSONL 和选择多次运行汇总 PDF。「实验记录」可查看配置及日志，暂停或中断后可恢复任务。正式运行数据库位于 runs/experiments.sqlite3。

独立功能验收使用 python smoke_test.py。
